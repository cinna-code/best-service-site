# Best Service — Wagtail CMS

Это отдельная CMS-версия текущего лендинга. Она использует тот же визуальный
стиль, но не связана с уже опубликованным статическим сайтом: до отдельного
переноса на Django-хостинг публичная страница остаётся без изменений.

## Первый запуск после клонирования

В PowerShell из папки `wagtail_cms`:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py bootstrap_bestservice
python manage.py createsuperuser
python manage.py runserver
```

Команда `bootstrap_bestservice` заполнит новую базу текстами, логотипами и
карточками сертификатов. Сканы намеренно не включены в публичный репозиторий:
после запуска добавьте их через раздел «Изображения» и выберите нужное превью
в карточке сертификата. Учётные данные администратора задаются только на вашем
компьютере и не хранятся в репозитории.

## Локальный запуск

Из папки `wagtail_cms`:

```powershell
..\.wagtail-venv\Scripts\python.exe manage.py runserver
```

Сайт откроется по адресу `http://127.0.0.1:8000/`.

## Первый вход в админку

Создайте свой пароль самостоятельно — его не нужно сообщать кому-либо:

```powershell
..\.wagtail-venv\Scripts\python.exe manage.py createsuperuser
```

После этого откройте `http://127.0.0.1:8000/admin/` и войдите с выбранными
вами данными.

## Что редактируется через Wagtail

- страница **Best Service**: каждый видимый заголовок, подпись, описание,
  кнопка, ссылка, пункт меню, узел схемы и строка бегущей ленты;
- повторяющиеся карточки услуг, IT-сопровождения, преимуществ, партнёров и
  сертификатов: можно добавлять, удалять, скрывать и менять порядок;
- раздел **Настройки → Настройки Best Service**: логотип, текст кнопки в
  шапке и весь подвал;
- разделы **Изображения** и **Документы**: загрузка логотипов, изображений
  сертификатов, PDF и других файлов.

В карточке сертификата доступны одновременно превью, файл для скачивания и
внешняя ссылка. Если превью ещё нет, сайт показывает фирменный макет-заглушку.

## Повторный стартовый импорт

Команда ниже заполнит пустую базу актуальным содержимым сайта, логотипами и
карточками сертификатов без сканов:

```powershell
..\.wagtail-venv\Scripts\python.exe manage.py bootstrap_bestservice
```

`--refresh` намеренно перезаписывает контент стартовой версией, поэтому после
начала ручного редактирования его использовать не нужно.

## Перед размещением в интернете

Wagtail требует Python/Django-сервера и базы данных. Его нельзя разместить на
текущем статическом хостинге без переноса. Когда выберете сервер, понадобятся
переменные окружения `DJANGO_SECRET_KEY`, `DJANGO_DEBUG=false`,
`DJANGO_ALLOWED_HOSTS` и `WAGTAILADMIN_BASE_URL`; SQLite для старта можно
заменить на PostgreSQL. Исходный код готов к переносу отдельно от текущего
публичного сайта.
